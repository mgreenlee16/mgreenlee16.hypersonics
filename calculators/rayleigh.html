Rayleigh Flow

Constant-area, frictionless flow with heat addition. Get the starred ratios from any one quantity, or the exit state for a given total-temperature rise.

Process: inlet M₁ and T₀₂/T₀₁

Relations used

$$\frac{p}{p^*} = \frac{1+\gamma}{1+\gamma M^2},\quad \frac{T}{T^*} = \frac{(1+\gamma)^2M^2}{(1+\gamma M^2)^2},\quad \frac{T_0}{T_0^*} = \frac{(\gamma+1)M^2[2+(\gamma-1)M^2]}{(1+\gamma M^2)^2},\quad \frac{p_0}{p_0^*} = \frac{1+\gamma}{1+\gamma M^2}\left[\frac{2+(\gamma-1)M^2}{\gamma+1}\right]^{\frac{\gamma}{\gamma-1}}$$

Heat added per unit mass: \(q = c_p(T_{0,2}-T_{0,1})\). See Lesson 4.
