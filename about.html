About this site

Compressible Flow Lab is a self-study site for compressible aerodynamics. The format (short derivations paired with live, adjustable figures, plus calculators that replace the tables) was inspired by Kursat Kara's open Fundamentals of Aerodynamics course site.

How it is built

Plain HTML, CSS and JavaScript with no build step, so it runs straight from GitHub Pages. All physics lives in one file, assets/js/gasdyn.js: the isentropic, normal-shock, oblique-shock, Prandtl–Meyer, Rayleigh and Fanno relations, shock-expansion theory, compressibility corrections, and the 1976 U.S. Standard Atmosphere. Lessons and calculators call the same functions. Equations are typeset with KaTeX.

Accuracy

The functions reproduce the standard tables. For M = 2 and γ = 1.4: p₀/p = 7.824, A/A* = 1.688, normal-shock p₀₂/p₀₁ = 0.7209, a θ = 10° wedge gives β = 39.31° (weak) or 83.70° (strong), θmax = 22.97°, ν = 26.38°, Fanno 4fL*/D = 0.3050, and Rayleigh T₀/T₀* = 0.7934. Inverse problems are solved by bisection to near machine precision.
